# Nagori · 名残

Une petite gare japonaise qui vit en même temps que toi : même heure, même météo, même micro-saison qu'au Japon. Chaque jour, quelqu'un descend du train.

Maquette en cours de développement. Les textes et les dessins sont provisoires.

Le code est écrit avec l'aide de Claude. Les images, la musique et les textes du jeu final seront faits par des humains, et chaque œuvre sera créditée.

Météo : [Open-Meteo](https://open-meteo.com/).
